# Changelog

## 1.0.1 (Nov 22, 2026)
- Epic offers on games that are already free-to-play (Epic's regular price is 0, such as an in-game item bundle) are now posted as "In-game bonus on Epic (game is free-to-play)" with a note to check the store page, instead of "is free on Epic".
- Epic add-ons now say they need the base game.
- If Epic's data has no price, the offer is treated as a normal giveaway, as before.
- 5 new tests.

## 1.0.0 (Oct 18, 2026)
- First stable release: posts Epic Games Store free games to a Discord channel through a webhook.
